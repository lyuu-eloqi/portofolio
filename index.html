Web Application Pengembangan Mandiri

SIAP-TERNAK – Sistem Prediksi Ternak Ayam Berbasis Analitik Cerdas

Aplikasi berbasis web yang dirancang secara mandiri untuk membantu pengelolaan siklus peternakan ayam melalui pemodelan analitik data pakan, bobot, dan estimasi keuntungan atau kerugian secara terstruktur.

Kontribusi Penuh Mandiri: Melakukan analisis kebutuhan, perancangan skema database relasional MySQL, perancangan antarmuka pengguna (UI/UX), serta penulisan kode frontend dan backend secara utuh.
Formula Analitik & Prediksi: Mengimplementasikan metode Linear Regression dan Moving Average untuk proyeksi bobot ternak dan estimasi finansial siklus pemeliharaan.
Evaluasi Akurasi & Early Warning: Menerapkan evaluasi galat MAPE (Mean Absolute Percentage Error) dan modul indikator dini (*early warning*) saat rasio konsumsi pakan tidak proporsional.
Keterbukaan Data Validasi:

Pengujian formula prediksi diuji menggunakan dataset simulasi matematis untuk mengevaluasi presisi kalkulasi algoritma. Sistem ini merupakan karya akademik/portofolio mandiri dan tidak diklaim telah diterapkan pada operasional lapangan aktual BUMDes.

Laravel PHP MySQL Vue.js JavaScript Bootstrap HTML5/CSS3

8Core-Agenda – Aplikasi Desktop Pengarsipan Surat

Aplikasi desktop yang dibangun untuk memodernisasi tata kelola administrasi surat masuk dan surat keluar di lingkungan rumah sakit, menggantikan sistem pencatatan buku agenda fisik.

Fitur Pengarsipan: Penomoran otomatis agenda surat masuk dan keluar, pengelompokan klasifikasi surat, pencarian disposisi cepat, dan cetak rekapitulasi data arsip.
Kontribusi Tim & Teknis: Mengembangkan antarmuka modul agenda menggunakan Java, integrasi penyimpanan basis data lokal MySQL, serta pengujian fungsionalitas form.
Dokumentasi Komprehensif: Menyusun dokumen spesifikasi teknis sistem dan buku panduan pengguna (*user manual*) guna memudahkan staf non-teknis.
